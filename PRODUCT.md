# ScamPath

ScamPath helps someone decide whether to pause before responding to a message that asks for money or sensitive information. It reviews the conversation the user supplies, in order, and points to the lines where risk appeared.

The prototype assumes a single Android screen. The user pastes or shares text or reads a screenshot, then checks the reviewed text. The rule-based detector responds first. The user can request a longer local explanation. The app has no background inbox access.

A light, high-contrast interface uses a teal primary action and places the verdict and its timeline together. Amber is reserved for concern. Android text, buttons and keyboard controls keep interaction familiar. The first milestone is scam communications. Link observations add evidence within that flow.
